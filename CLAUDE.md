# Скоуп — сайт skoup.ru

Лендинг продуктовой дизайн-студии «Скоуп» (финтех, банки, регуляторика). Вся копия на русском.

## Жёсткие правила контента
- Нигде не упоминать Module / module.agency.
- Дизайн чистый, минималистичный, с воздухом. Ничего не «украшать» от себя — только то, что есть в макете.

## Стек
- Astro + TypeScript, без UI-фреймворка на клиенте. Обычный CSS (без Tailwind).
- Токены: `src/styles/tokens.css` (сгенерированы из Figma-переменных), стили текста: `src/styles/typography.css` (`.t-h1` … `.t-display` = текстовые стили Figma).
- Шрифты self-hosted: Manrope 500, Geist Mono 300/500 (кириллица + латиница, woff2, preload).
- Картинки: обложки кейсов в двух кадрированиях (Desktop / Mobile) → `<picture>` AVIF/WebP, lazy. Халфтон-иллюстрации — SVG.
- UI-анимации кнопок и меню — по скиллу `better-ui` (`.claude/skills`): transitions, не keyframes; press `scale: 0.96` 150ms ease-out (не для disabled); hover только под `@media (hover: hover)`; hover-скругление кнопок — до половины высоты (`--btn-height / 2`), не до 999px; движение — только под `prefers-reduced-motion: no-preference`.
- Иконки — `src/components/Icon.astro` (SVG Amicons в `src/assets/icons/amicons/`, `currentColor`). Цвета иконок карточек — `icon/*` (классы `.icon-green` … в `base.css`).
- Главная (`src/components/home/*`): вордмарк «СКОУП» (SVG `746:12767` / `746:12770`, на мобильном шире колонки; при скролле уезжает медленнее страницы — 0.4 — и гаснет: desktop за полэкрана, контент наезжает; mobile — ровно к моменту, когда заголовок до него доезжает, без наложения: `src/scripts/hero-wordmark.ts`, Motion `scroll()`), «Что мы умеем» — 5 Service card в 2 колонки по 688, кейсы, форматы, «Кто мы» (фраза с Brand link — ссылки на сайты клиентов в новой вкладке, аватары Team avatar −12: при наведении поднимается без тени, соседи приглушены вуалью цвета фона; Fact card; отзывы Раунд и Uzum — сменяются прозрачностью), блог (Article card; тизер Passkeys без ссылки, кнопка «Скоро»), CTA с галереей (`shots-drift.ts`: лента едет влево со скроллом и растягивается пружинами, масштаб 0.75 на мобильном). Фиксированная кнопка «Заполнить бриф» (`StickyBrief.astro`, макета нет): внизу по центру, 24 px от низа, по ширине текста; появляется после первого экрана, уходит на CTA и при открытом брифе (IntersectionObserver). Презентация — ссылка на Google Диск (`CTA.presentation` в `src/data/site.ts`), новая вкладка. Шапки, меню и футера на новой главной нет.
- Колонка текста — `--layout-column-width` (688) в `base.css`.
- Типограф при сборке (`scripts/typograph-integration.mjs`, хук `astro:build:done`): во всём HTML короткие слова (1–2 буквы, «для / без / при / про / под / над») привязаны неразрывным пробелом к следующему, тире — к предыдущему; `script`, `style`, `svg` не трогает. Вручную `&nbsp;` в тексте ставить не нужно.
- Плавный скролл — Lenis (`src/scripts/smooth-scroll.ts`, подключён в `Base.astro`): инерция колеса/тачпада (lerp 0.1), тач — нативный; якорные ссылки — свой обработчик (1,2 с, expo out; из мобильного меню — после его закрытия). При открытом меню Lenis остановлен. Пока страница прокручивается, спокойная WebGL-иллюстрация первого экрана не перерисовывается (держит кадр), иначе скролл подтормаживает; если курсор рядом с точками или они ещё в движении — рисуется дальше (иначе разлёт застывает). Положение мыши иллюстрация пересчитывает каждый кадр по координатам в окне: колесо двигает страницу под неподвижным курсором без pointermove. При `prefers-reduced-motion` Lenis не включается.
- Полоса прокрутки — своя (`src/scripts/scrollbar.ts`, стили в `base.css`): системная скрыта у страницы и брифа; тонкий ползунок у правого края виден при прокрутке и гаснет через 1 с, под мышью толще, тянется, клик по дорожке — переход; при открытом брифе показывает и крутит бриф. Страницу двигает через Lenis (`getLenis()`), на тач-экранах не ловит касания.
- Кейсы при скролле (`src/scripts/case-parallax.ts`): рамка скруглена 40 px (токена нет, по просьбе); наведение (`case-hover.ts`) — картинка приближается, курсор над обложкой заменяет общая плашка «Скоро покажем» (пружина, вытягивание по скорости, перелетает между кейсами); двигается только картинка внутри рамки (scale 1.08), от входа карточки в окно до выхода −24…+24 px (mobile ±12), translate3d в rAF только для видимых карточек (IntersectionObserver), источник — scroll окна (его же двигает Lenis); при reduced motion выключено.
- Бриф — полноэкранный `<dialog>` поверх главной (`src/components/brief/*`, логика `src/scripts/brief/*`). Открывается по CTA с `data-brief-open` (ссылки остаются `mailto:` без JS) и по `/#brief`; закрывается ×, Esc, «Назад», «На главную». Открывается `show()`, не `showModal()` (модальность пересчитывает стили всей страницы — рывок в первом кадре): `aria-modal`, ловушка фокуса и Esc — свои, затемнение — `.brief-shade`. Закрытый бриф разложен заранее (`visibility: hidden`), overflow страницы не трогаем (иначе пропадает полоса прокрутки и страница прыгает). Панель снизу 700 мс `cubic-bezier(0.76, 0, 0.24, 1)`, страница под ней `scale 0.96` и затемнение, контент лесенкой; reduced motion — fade 200 мс. Ошибки — только после первой отправки, дальше на лету. Телефон — маска `+7 (999) 123-45-67`. Отправка — `PUBLIC_BRIEF_ENDPOINT` (multipart), без него мок 800 мс. Chip — `src/components/Chip.astro` (632:7889). Закрытие — Round button Filled. Футера в брифе нет.
- Остальные анимации (позже): отдельные скрипты, canvas/WebGL, обязательно `prefers-reduced-motion`.

## Адаптив
- Брейкпоинты макета: Mobile 393, Desktop 1440. Между ними — резина: adaptive-токены уже интерполируются `clamp()` в `tokens.css`.
- Структурные перестроения (столбик карточек, кнопки на всю ширину) — через `@media (max-width: 767px)`.
- Шапки, меню и футера на сайте нет.
- Фоны секций — на всю ширину окна, контент — в колонке 1440: горизонтальные поля через `--container-pad` (= `--layout-page-padding` до 1440, дальше центрирует). Вертикальные отступы секций — `--layout-section-padding`.
- Adaptive-токены пересчитываются из переменных Figma: обновить `scripts/figma-vars/*.json` и запустить `node scripts/adaptive-tokens.mjs`.

## Статья
- `/blog/marketplaces-installments` (`src/pages/blog/*`, `src/components/article/*`): секции чередуют surface/primary и surface/tertiary, иллюстрации — экспорт кадров макета 2x (`src/assets/article/img/`, углы прозрачные — скругление в самой картинке, без CSS-обрезки) → AVIF/WebP/PNG, на мобильном в масштабе 0.6 с горизонтальной прокруткой; «Норма» — `Note.astro`; «Итог» — настоящая `<table>`; на мобильном плашка на всю ширину экрана, первая колонка залипает, площадки листаются под неё.
- Навигация (`ArticleNav.astro` + `src/scripts/article-nav.ts`): кнопка внизу по центру (24 px от низа), подпись — текущий раздел, в оглавлении он подсвечен; видна всё время между первым экраном и оффером «Заполнить бриф», на первом экране, оффере и в футере спрятана; оверлей — градиент static/black 40% снизу → прозрачный вверху (размытие убрали по просьбе); панель вырастает из кнопки, иконка строк превращается в крестик; Esc, клик по оверлею, «Закрыть», пункт — плавный скролл через Lenis.
- Шапка (`ArticleHead.astro` + `src/scripts/article-head.ts`, Figma `746:12778`): крошки «Главная / название» (`Crumbs.astro`, те же, что в первом экране) на полосе во всю ширину, desktop 84; на первом экране статьи не показывается совсем, ниже — выезжает при скролле вверх и уезжает при скролле вниз (порог 12 px). Фон — прогрессивное стекло: 4 слоя `backdrop-filter` 2/4/8/16 px под масками (сверху сильнее, к низу сходит на нет) + белая дымка 63 % → 0; `-webkit-backdrop-filter` — в атрибуте `style` (из CSS сборка его выбрасывает).
- Переход между страницами — View Transitions (`@view-transition` в `base.css`): заголовок карточки статьи перетекает в заголовок статьи (`data-vt-title`), остальное — fade + подъём; при reduced motion выключен.

## Юридические страницы
- `/privacy/` и `/consent/` (`LegalPage.astro`, ссылки — `LEGAL` в `src/data/site.ts`, из согласия в брифе — в новой вкладке). Пока заглушки (`draft`): noindex и не в sitemap (фильтр в `astro.config.mjs`). Когда придёт текст — передать его в слот, снять `draft` и убрать адрес из фильтра sitemap.

## Компоненты (имена = имена в Figma)
Button, RoundButton, ButtonSmall, Chip, TeamAvatar, BrandLink, ServiceCard, FormatCard, FactCard, CaseCard, ArticleCard, ArticleImage, ArticleNav, Input (brief/Field), FileUpload, Icon.
